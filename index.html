// TCP_CONNECTION_LIFECYCLE

TCP 3-Way Handshake (Connection Setup):
  • 1. SYN: Client sends packet with SYN flag and initial sequence number ($ISN_c$). State: `SYN_SENT`.
  • 2. SYN-ACK: Server acknowledges with its own SYN and ACK ($ISN_c + 1$). State: `SYN_RECEIVED`.
  • 3. ACK: Client acknowledges server sequence number (`$ISN_s + 1$). Connection established! State: `ESTABLISHED`.
TCP 4-Way Termination & Sockets:
  • Termination: Involves exchange of FIN and ACK flags. Transitions through `FIN_WAIT_1`, `FIN_WAIT_2`, and `TIME_WAIT` (2MSL timeout).
  • Socket Tuple: Every active connection is uniquely identified by a 5-tuple: (Protocol, Src IP, Src Port, Dst IP, Dst Port).

Note on Default Gateways: The default gateway is the router interface IP address used by local hosts to forward traffic destined for outside networks (e.g., the internet). By industry convention, it is assigned the first usable IP address in the subnet range (Network ID + 1).
