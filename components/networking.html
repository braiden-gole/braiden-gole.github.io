// DNS_RESOLUTION_PIPELINE & SECURITY

Iterative / Recursive Query Lifecycle:
  • 1. Stub Resolver Cache: OS and browser check local memory (TTL expiration check).
  • 2. Recursive Resolver: ISP/Public resolver (e.g., 1.1.1.1) handles client delegation.
  • 3. Root (`.`) & TLD (`.com`): Root directs to TLD nameservers; TLD returns Authoritative NS records.
  • 4. EDNS0 Extensions: UDP payload size expansion up to 4096 bytes to avoid TCP fallback overhead.
DNSSEC Cryptographic Validation:
  • RRSIG: Digital signatures cryptographically binding resource record sets to public keys.
  • DNSKEY & DS: Chain of trust established upward from zone signing keys to root anchor.
  • Anycast Load Balancing: Routing DNS queries across globally distributed edge nodes for minimal latency.

// TCP_LIFECYCLE, FLOW CONTROL & SOCKETS

TCP State Machinery & Handshakes:
  • 1. SYN: Client sends initial sequence number ($ISN_c$). State: SYN_SENT.
  • 2. SYN-ACK: Server responds with $ISN_s$ and ACK ($ISN_c + 1$). State: SYN_RECEIVED.
  • 3. ACK & Termination: Client ACKs server sequence. 4-way teardown transitions through FIN_WAIT_1, FIN_WAIT_2, and TIME_WAIT (2MSL timeout).
Flow, Congestion Control & Sockets:
  • Sliding Windows: Dynamic receiver buffer advertised window preventing buffer overflows.
  • Congestion Control: Slow Start, Congestion Avoidance, Fast Retransmit, and modern BBR/CUBIC algorithms.
  • Socket 5-Tuple: Unique connection identifier: (Protocol, Src IP, Src Port, Dst IP, Dst Port).

// QUIC_AND_HTTP3_TRANSPORT

UDP Transport & TLS 1.3:
Runs in user-space over UDP with native cryptographic protection. Merges transport and security handshakes, enabling 0-RTT connection resumption for repeat clients.
Stream Multiplexing:
Completely eradicates TCP Head-of-Line (HoL) blocking. Individual application streams are isolated; packet loss on stream $A$ never stalls data delivery on stream $B$.
Connection Migration:
Identified via a persistent 64-bit Connection ID rather than IP/Port pairs. Seamlessly maintains state when clients roam between Wi-Fi and cellular networks.

// NAT_TRAVERSAL_ICE_STUN_TURN

NAT Behavioral Classifications:
  • Full & Restricted Cone: Allows inbound traffic from external sources once an outbound mapping is established.
  • Symmetric NAT: Allocates a unique external port per destination IP/port pair, blocking standard P2P hole-punching and necessitating relay servers.
ICE Candidate Framework:
  • STUN: Discovers local reflexive public IP and port mappings behind stateful routers.
  • TURN: Relays media/data streams through an intermediate proxy when symmetric NAT restrictions prevent direct connectivity.
  • Candidate Prioritization: Sorts pathways (Host > Server Reflexive > Relayed) to establish optimal low-latency connections.

// IPV6_ARCHITECTURE_AND_NDP

Address Structure & SLAAC:
  • 128-bit Space: 8 groups of 16-bit hexadecimal values separated by colons (e.g., 2001:db8::/32).
  • SLAAC: Stateless Address Autoconfiguration allowing hosts to self-generate globally unique IPs using Router Advertisements (RA).
  • EUI-64: Deriving interface identifiers dynamically from MAC addresses by flipping the 7th bit.
Neighbor Discovery Protocol (NDP):
  • Replaces IPv4 ARP, broadcast storms, and DHCP dependency using ICMPv6 multicast groups.
  • Neighbor Solicitation / Advertisement: Resolves link-layer addresses and detects duplicate addresses (DAD).
  • Router Solicitation: Rapid discovery of local gateways upon interface initialization.

// BGP_AND_OSPF_ROUTING_PROTOCOLS

BGP (Border Gateway Protocol - EGP):
  • Path-Vector Routing: Operates the core of the global internet, exchanging reachability info between Autonomous Systems (AS).
  • AS-Path Attribute: Prevents routing loops by tracking every AS hop a packet must traverse.
  • Policy-Based Routing: Enforces business, economic, and security routing metrics over pure shortest-path algorithms.
OSPF (Open Shortest Path First - IGP):
  • Link-State Routing: Uses Dijkstra's algorithm to compute the shortest path tree across enterprise interiors.
  • Link-State Advertisements (LSAs): Flooded across local areas to maintain an identical, synchronized topology map.
  • Area Hierarchies: Backbone Area 0 segmentation isolating topology changes to minimize convergence overhead.

// TLS1.3_AND_ENCRYPTED_CLIENT

TLS 1.3 Handshake Optimization:
  • 1-RTT Handshake: Strips obsolete cipher suites and reduces negotiation round trips to a single pass.
  • Forward Secrecy (PFS): Ephemeral Diffie-Hellman keys ensure historical session captures cannot be decrypted if long-term private keys are compromised.
Encrypted Client Hello (ECH):
  • Encrypts the initial SNI (Server Name Indication) field within the outer TLS handshake wrapper.
  • Prevents third-party ISP wiretapping and SNI-based domain censoring at the network edge.

// WEBSOCKETS_AND_SSE_TRANSPORT

WebSocket Protocol (RFC 6455):
  • HTTP Upgrade Handshake: Initiates via standard HTTP/1.1 GET request with Upgrade: websocket headers, transitioning the TCP socket to full-duplex framing.
  • Framing & Masking: Lightweight binary/text framing with client-side XOR masking to prevent intermediate proxy cache poisoning.
Server-Sent Events (SSE / EventSource):
  • Unidirectional server-to-client streaming natively over standard HTTP/2 streams.
  • Built-in automatic reconnection logic, last-event-ID tracking, and simplified text/event-stream MIME formatting.
